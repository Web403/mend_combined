Seeding Overview
The full dependency chain — seed in this order to ensure data integrity.
Seed Hotel
Creates a hotel tenant via Admin credentials. Sets hotel token for all subsequent calls.
Default password: hotel1234
Seed Users
Creates N users via hotel token. Each gets a template prefix so you can identify them.
Seed Shifts
Creates shifts and assigns seeded users. Uses hotel manager token.
Seed Attendance
Clocks seeded users in/out. Coordinates must be inside hotel geofence. You control whether violations are created.
ℹ️ Clock-in then clock-out is called sequentially per user. Hotel coords are passed so geofence passes.
Seed Tasks
Assigns tasks to seeded users and marks them completed. Drives OPH / efficiency scores.
Seed Wellbeing
Submits daily wellbeing for seeded users. Controls fatigue risk tier for testing alerts.
ℹ️ Wellbeing uses the hotel token (hotel posts on behalf of user). One entry per user per day enforced.
Seed SOS Alerts
Triggers SOS events for selected users. Tests notification chain.
Seed LMS
Creates a course → lecture → assessment → enrolls users → marks lectures complete → submits assessment attempt (pass). Generates certificates that feed the Passport.
Seed Mend Passports
Creates a Mend Passport for each seeded user, then syncs live LMS + efficiency data into it.
Seed Recruitment
Creates job postings, publishes them, then applies with seeded users and progresses applications.

Evaluate Compliance
Triggers the compliance engine for the seeded hotel. Computes score, assigns certification tier, writes audit log.
ℹ️ Requires admin token. After evaluation the result is displayed below and compared against expected tier.
